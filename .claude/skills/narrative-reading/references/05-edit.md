# 工程5 一冊としての編集

通しで読む。**章単位で読まない。** 章ごとには美しいが一冊としては散漫、という状態を見つけるのがこの工程。

## 見るもの

### 1 冒頭の問いが終章でどう深まったか

工程2で決めた中心の問いが、終章で答えられているか。冒頭の情景と終章の情景が響き合っているか。

**印象的な冒頭と印象的な終章が、無関係に並んでいないか。**

### 2 各章が違う発見を渡しているか

同じ結論に何度も戻っていないか。第7版では全章が中心テーマへ収束し、読者が同じ話を11回読む形になっていた。

### 3 同じ働きの文が連続していないか

```
「ここからが、あなただけのものです」   ← 転換文。毎回同じだと装置が透ける
「思い当たることはありませんか」      ← 章末の欄。11回ある
```

**言い回しが毎回同じなら書き分ける。**

### 4 救われる側が、救う側だけになっていないか

**これが最も重要な点。**

月の「溺れかけた男が救助されようとしている」という象徴が、本文で「人を引き上げる場所をつくる」へ移り、終章で「溺れた者を引き上げる手」として回収される、ということが起きた。

せっかく現れた「**助けを受け取る自分**」が、再び「人の役に立つ自分」に戻っている。

あらゆる象徴を最後には才能・使命・貢献へ変換する癖がある。**痛みや損失は、それ自体として受け止める。** 力を発揮する以外の在り方にも価値があることを描く。

```
避ける  「ここには人を救う使命があります」
狙う    「ここでは、あなたまで救う側に戻らなくていい」
```

ただし**全員に「頑張らなくていい」と書くのではない**。人によっては、自分の欲求を表に出すことや責任を引き受けることが新しい選択になる。共通させるのは結論ではなく、**読者を一つの役割に閉じ込めず選択肢を増やす姿勢**。

十本の指の比喩も同じ。「今まで二本しか使えていなかった」という不足の物語より、「**これまで名前を知らずに使ってきた力を、一つずつ認め直す**」という物語にする。

### 5 制作上の説明が本文に漏れていないか

```
「三処方とも中心のエレメントは統一し、ディスポジター連鎖を辿らないようにしました」
```

これは内規の説明であって鑑定の判断ではない。読者が知りたいのは「なぜその星を中心に選んだか」。

## 最後に作るもの

### 持ち帰れる一文

一冊を通じて読者が受け取った発見を、**専門用語を知らない人にも伝わる平易な言葉**へ育てる。本文の具体的な読み解きから生まれたものにする。

例
> 人に任せるのは、思いを薄めることではない。自分のいない時間にも、その思いが育つようにすることだ。

**工程2で先に決めない。** 先に決めるとそこへ向けて書いてしまい予定調和になる。通しで読んだあとに抽出する。

### 試せる一行動

その発見とつながる、小さく試せる行動。次に似た場面に出会ったとき何を変えればよいかが分かる形。

例
> 次に仕事を頼むとき、「大切にしたい目的」と「相手に判断を任せる範囲」を、一緒に伝えてみる。

## なぜこれが口コミにつながるか

読者が友達へ話す内容が変わる。

```
前  「神話がたくさん出てきて、すごかった」
後  「自分で抱え込む理由が少し分かって、人への頼み方を変えてみようと思えた」
```

口コミ用の名言を外から貼りつけるのではなく、**鑑定の中で起きた理解を持ち運べる言葉にする**。

## 完成条件

鑑定書の完成は、全章を書き終えた時点ではない。**読者が受け取ったものを自分の言葉で話せる状態**になった時点。
