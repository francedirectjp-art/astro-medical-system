**着手前に必読。** ここに書かれた事故は全部、実際に起きたもの。

## 最優先の教訓

> **数字だけ見て成功と判断しない。ページ数の落差が最良の異常検知。**

42ページ→25ページに落ちたとき、字数は「18,000字に近づいた」と改善して見えた。実際は章題の指示が落ちて**章扉が全滅**していた。

> **NGが出たら、まず誤検出を疑う。**

検品ツールの誤検出のほうが本物の不具合より多い。確認せずに直すと正しい文を壊す。

## 検品ツールの誤検出

| 誤検出 | 原因 |
|---|---|
| 「書き直している深夜」 | 場面描写をメタ発言と誤判定 |
| 「進行の太陽は…進行の月は第7ハウス」 | 係り先の取り違え |
| 「この月が今置かれているのは」 | 指示語の主語 |
| 中庭の推量を直前の章に合算 | 章の区切り漏れ |
| 「接触はいずれも1度以内」 | 「いずれも」を未来形と誤認 |
| 神話版で「天王星の言及なし」 | 神名（ウラノス）未対応 |
| 「三滴」で処方0件 | 漢数字未対応 |
