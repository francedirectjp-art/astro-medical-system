# 工程2 編集方針の設計

**本文を書く前に、この一冊が何を読み直す本なのかを決める。**

## なぜ必要か

工程3は4便に分かれており、各便は独立して生成される。**一冊としての設計図がどこにもないと、章ごとには美しいが一冊としては散漫**になる。

第8版までは「感動的に書いてください」だった。これを「**この人が自分の人生をどう読み直せる一冊なのかを先に設計してください**」へ移す。

## 何を決めるか

A4半ページ。確定データと本人の三つの答えだけを根拠にする。

```
中心の問い     この人の人生を貫く一つの問い
これまでの見方  読者がこれまで自分をどう捉えてきた可能性があるか
差し出す見方   この鑑定を通じて持てる別の見方
根拠          その問いを支える確定データ（配置・元素・軸・本人の答え）
終章の着地     冒頭とどう響き合わせるか
```

★**各章の役割を書いてはいけない。** 第8版の初期案では「第1章の役割／第3章の役割…」を
方針に列挙していたが、これは字数を増やす指示として働いた。各章に「これも書け」という
追加要求を渡したことになり、織田様の版で第2章が仕様の192%まで膨らんだ。

章ごとに何を書くかは `03-compose.md` の仕事である。ここで書くと二重指示になる。
**方針が渡すのは、一冊を貫く問いだけ。**

例（山田恭世さま）

```
中心の問い    人に必要とされながら、自分の自由も守ることはできるのか
これまでの見方 自分が全部引き受けなければ回らない、と思ってきた
差し出す見方   任せることは、思いを薄めることではない
根拠         太陽が天職の領域で自分の神殿／月が敵地／主神はヘルメス
終章の着地    冒頭の情景と響き合わせ、選べる状態を描く
```

## 運用

- 生成した編集方針を**全4便のプロンプトに毎回添付**する
- 資料から別の重要な側面が現れたら、工程5で更新する
- 「任せること」を全員の結論にしない。**その人ごとに問いを設計する**

## 禁止

- 中心の問いを決め打ちしない（配置と本人の答えから導く）
- **持ち帰る一文をここで決めない。** 工程5で本文から抽出する。先に決めると予定調和になる
