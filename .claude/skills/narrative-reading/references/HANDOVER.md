## 今日わかった重要なこと

### 字数超過の原因（24%）

```
① 編集方針に「各章の役割」を書いた    → 各章に追加要求を渡していた（第2章192%）
② 仕様字数が実態と乖離               → 第1章135%・第2章154%・次の扉169%（方針なしでも）
③ モデルは字数目標を守らない          → 目標3,600の便が5,757字（+60%）
```

対処は済んでいる。**①方針から章の役割を削除／②仕様を実態へ再配分／③工程5で削る**。

**③が本質。** 生成時に絞るのは諦めた。制御ループは下振れには効くが上振れには効かない。

### 上限の変更

```
18,000字 → 20,000字（目安）／22,000字（許容上限）
```

18,000は26,000から削る過程で決めた数字で根拠が薄かった。実測が19,000〜22,000に収束する。
