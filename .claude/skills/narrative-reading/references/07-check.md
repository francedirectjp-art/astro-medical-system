# 工程7 機械検品

```bash
MYTH=1 CHART_TXT=<chart.txt> python3 check_reading.py <reading.md>
```

**合格が出るまで納品しない。**

## 14項目

| # | 項目 |
|---|---|
| 1 | 総字数 |
| 2 | 完了宣言 |
| 3 | 支配語の誤り（「太陽の支配する蟹座」型） |
| 4 | 括弧内否定（「（獅子座ではなく蟹座）」型） |
| 5 | 弱い推量（章ごと。上限1） |
| 6 | 三点セットの数（章数に連動） |
| 7 | 香りの配合重複 |
| 8 | 禁止術語（巻末資料は対象外） |
| 9 | メタ発言 |
| 10 | 停止案内・書式の漏れ |
| 11 | 本文の太字 |
| 12 | 「次の扉」への売り込み混入 |
| 13 | 記入欄（PDFでは罫線になるため原稿mdで見る） |
| 14 | **本文とデータの整合** |
| 15 | **サビアンの転換文**（最低4箇所） |
| 16 | **天体名の破損**（海アポロン星） |

`CHART_TXT` を渡さないと14が検査されない。**必ず渡す。**

## 誤検出の履歴

このツール自体が何度も誤検出を出した。**NGが出たら、まず本物か疑う。**

| 誤検出 | 原因 |
|---|---|
| 「資料を書き直している深夜」 | 場面描写をメタ発言と誤判定 |
| 「進行の太陽は…進行の月は第7ハウス」 | 係り先の取り違え |
| 「この月が今置かれているのは第7ハウス」 | 指示語の主語を取り違え |
| 中庭の推量が直前の章に合算 | 章の区切りに中庭がなかった |
| 「接触はいずれも1度以内」 | 「いずれも」を未来形と誤認 |
| 神話版で「天王星の言及なし」 | 神名（ウラノス）を見ていなかった |
| 「三滴」で香りの処方0件 | 漢数字に未対応 |

**本物の不具合より誤検出のほうが多かった。** 確認せずに本文を直すと、正しい文を壊す。

## 判断の順序

```
1  NGの該当箇所を本文で実際に見る
2  本物か誤検出かを判定する
3  本物なら本文を直す
4  誤検出ならツールを直す（そして旧版で本物を拾えるか再確認する）
```

4を怠ると、ツールが緩くなって本物を見逃すようになる。**ツールを緩めたら、必ず既知の不具合を持つ原稿で再検証する。**
