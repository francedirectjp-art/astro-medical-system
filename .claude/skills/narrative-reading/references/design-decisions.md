# 設計判断の記録

**変更を提案する前に読む。** なぜそうなっているかを知らずに直すと、過去に潰した問題が再発する。

## なぜ王国をやめて神話にしたか

第7版は王国メタファー（王・王妃・大臣・将軍・長老）だった。実測で、40ページの本に**男性名詞が100回超**。

構造的な問題は性別そのものではなく**階層**だった。

```
王妃      王の配偶者。従属する
アルテミス 誰の配偶者でもない。自分の領域を持つ
```

女性読者に「あなたの表の顔は王、あなたの心は王妃」と言うと、自分の内面を自分の中の男性に従属させる言い方になる。神々は対等で誰の配下でもない。

**神話は比喩ではなく語源**である点も大きい。Mercury は水星の英名そのもの、Uranus はウラノスそのもの。訳しているのではなく、もとの名で呼ぶだけなので借り物にならない。

庭版も作った（インナーガーデニング）。優しくアロマへの接続が自然だが、覚える語が増える。**神話版を採用。** 庭版・王国版は環境変数で残してある。

## なぜセクトを背骨にしたか

第7版までセクトは内部判定だけで読者には一度も見えていなかった。

昼を司る側（アポロン・ゼウス・クロノス）／夜を守る側（アルテミス・アフロディーテ・アレス）／境を行き来するヘルメス、という区分は**伝統的なセクトそのもの**。ヘルメスが冥界にも行ける唯一の神であることは「水星は太陽の側に従う」という規則と一致する。

**生まれた時刻が昼か夜かという、誰にでも検証できる事実**から、その人の構造を説明できるようになった。技法がそのまま物語になった唯一の例。

## なぜ城主をコードで決めるか

ODAが個別に判断すると、①再現性がない ②他の講師が引き継げない ③なぜその星なのか読者に説明できない。

点数優先で機械的に決める。**AIの裁量をゼロにした項目は、以後ゼロ件で推移している。**

## なぜ中庭を廃止したか

三重に重複していた。

```
第1章          太陽・月・ASC を厚く読む
中庭｜太陽と月  同じものをもう一度読む      ← 重複
章末の欄        全11章に思い当たりの問い    ← 中庭と同じ機能
```

さらに18,000字に絞って章が痩せた結果、**中庭が章と同じ大きさ**になり、息継ぎでなく独立した章として読まれた。

記入欄は全11章の章末へ分散。**中庭2箇所より多く、読んだ直後なので自然。**

## なぜ第6章をノード軸だけにしたか

キロン・PoF・ノードの三つを扱うと一つあたりが薄くなり、キロンとPoFは他章のテーマと重なりやすい。

ヘッドとテイルは180度で対になるので、**二つの絵を並べると人生の軸が一枚で見える。** テイル=すでに何度も見た景色、ヘッド=まだ行っていない景色。

## なぜサビアンを転換点にしたか

サイン・ハウス・品位はすべて「型」で、同じ配置の人には共通する。**一度ごとに違うのはサビアンだけ**であり、個別性を担保しているのはそこしかない。

品位はサビアンの後ろへ回した。絵を見せてから「その絵を生きるのが楽か工夫が要るか」を語る。品位が絵に奉仕する形になり、技術情報の羅列でなくなる。

## なぜ18,000字にしたか

26,000字版は67円。18,000字版は53〜58円。約2割減。

削ったのは各章の描写の厚みだけで、**構成要素は一つも欠けていない**。三点セットは「字数調整の対象外」と明記。行数が少なく効きが大きいため。

## なぜ工程を分けるか

28,000字のプロンプト1本に、世界観・文体・禁止事項・計算規則・章構成・字数配分が同居していた。**何か直すたびに別の場所が壊れた。**

データは厳密に管理し、解釈は根拠を持たせ、文章には自由を残す。最後にその三つがつながっているかを確かめる。
