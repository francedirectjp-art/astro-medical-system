# 工程3 本文執筆

## 便の構成

`gen_v8.py` の `BLOCKS`。実測で次便の目標を自動補正する。

| 便 | 範囲 | 目標 |
|---|---|---|
| 1 | はじめに／序章／第1章／第2章 | 5,800字 |
| 2 | 第3〜5章 | 4,400字 |
| 3 | 第6〜9章 | 4,500字 |
| 4 | 第10章／問いへ／第11章／終章／次の扉／十柱の一覧 | 3,800字（繰越対象外） |

**最終便は繰越の対象外。** 終章と締めの二ページが痩せるのを防ぐ。

目標の7割（最終便は8割）を切った便はその場で書き直させる。

## 章の型（7段）

```
1 実感      読者の日常の一場面。身体感覚を必ず入れる
2 司るもの   その神が何を司るか
3 型        どの国（サイン）・どの領域（ハウス）  ← ここまでは同じ配置の人に共通
4 固有      その度数の絵（サビアン）              ← ★転換点
5 格        品位。その絵を生きるのが楽か工夫が要るか
6 代償と尊厳
7 上昇      引用できる一文で閉じる
```

## サビアンの扱い（最重要）

**サビアンだけが個別性を担保している。**

```
サイン   獅子座の太陽を持つ人は世界に何億人もいる
ハウス   12分の1。同じ配置は無数にいる
品位     型で自動的に決まる
サビアン  1度ごとに違う
```

だから絵を開く前に必ず転換の一文を置く。

> ここまでは、同じ配置を持つ方になら、どなたにも当てはまります。
> ここからが、あなたの度数だけが持つものです。

**言い回しは毎回変える。** 同じ文を十回繰り返すと装置が透けて見える。

絵は型を補強するためでなく、**型と突き合わせるために**使う。獅子座の太陽が「縁側で椅子を揺らす老いた船長」なら、華やぎとは正反対だと述べる。絵と型の関係を必ず一文で書く。**絵を出して終わりにしない。**

第1章の初出時のみ「空の三百六十の度数には、それぞれ一枚の絵が与えられています」と一度だけ説明する。

厚く描く情景は**一章にひとつ**。

## 章末の三点セット（第1〜10章に例外なく）

```
【星を読まれる方へ】
  度数まで書き、この章でどういう技術的判断をしたかを一行。
  第1章の初出のみ「ご存じない方は読み飛ばしてくださって構いません」。
  ★この欄も本文。術語禁止が適用される。ソーラーアーク・ディスポジター等を書かない。
  ★制作上の都合・内規の説明を書かない。

【思い当たることはありませんか？】
  日常の一場面を挙げて尋ねる。二〜三文。
  問いのあとに必ず全角カッコの記入欄を一行。
  ★全11章のうち三章では、問いを「過去の特定の年月」にする（年表から採る）。

指の回収
  一行。第1章末=2本、第3章末=5本、第4章末=8本、第5章末=10本。
  行頭に「第1章末」のような欄外ラベルを書かない。
```

## 「はじめに」十段（固定テンプレ）

差し込みは**五段目と六段目だけ**。他は全冊共通。

```
一  歓迎と名乗り
二  鑑定日の意味づけ
三  これまでへの敬意（翼を畳んできた／それは弱さではない）
四  二つのコードの宣言（デスティニー／ディグニティ＋エッセンシャルディグニティ）
五  謎その一 あなた自身の謎（占いは当てるものでなく思い当たるもの）★
六  謎その二 未来の謎（予見はすでにあなたの中にある）★
七  見た瞬間の印象  ← 差し込み。ASCとMCのサビアンから相反する二つを採る
八  使命の一行      ← 差し込み。ドラゴンヘッドから
九  三部構成の予告
十  締め（深呼吸・伝説）
```

十本の指は**序章**で一段落だけ。「はじめに」では触れない。

## 文体規約

| | |
|---|---|
| 弱い推量 | 「〜ではないでしょうか」は**章1回まで**。序章・終章も各1回 |
| 確認の問い | 「〜ありませんか」型。これは弱い推量に数えない |
| 配慮の可能性形 | 指のメタファーの「かもしれません」は数えない |
| 完了宣言 | **禁止**。「もう繰り返される必要のない物語になりました」等 |
| 価値の肯定 | 減らさない。「欠けているものは何もありません」は残す |
| 太字 | **本文に一切使わない** |
| 命令形 | 香りの実践と記入欄以外で使わない |
| 支配関係 | 「◯◯の支配する△△座」と書かない。「△△座の主神は◯◯」 |
| 術語併記 | 翻訳語だけ。括弧で術語を補わない |

## 香りの規則

```
中心3滴  その星がいま立っている星座のエレメントの主植物
従1滴    同じエレメントから
残り3滴  他の3エレメントから各1滴
合計     7滴
```

三処方（王／調整／年）は**必ず突き合わせて重複を確認**する。城主と年主星が同一天体なら中心が重なるので、従の一滴を差し替えて区別する。

**中心に立てられない植物**（ブラックペッパー・ジンジャー・シナモン）が当たったら同エレメントの別植物へ振り替える。逃げ場がない状態を作らない。

天体別主植物表にない星（キロン等）は**エレメント代表植物**（火=ローレル／風=ローズマリー／水=ネロリ／土=シダーウッド）。
