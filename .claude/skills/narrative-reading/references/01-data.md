# 工程1 データ確定

**AIを一切介在させない。** ここで確定した値が、以降すべての根拠になる。

## 入力

MyASPシナリオ `N2hq9AJ5`（【自動発行】星の鑑定書）の自由項目。

| 項目 | 内容 |
|---|---|
| free1 | 生年月日（例: 1979.8.1） |
| free2 | 出生時間（例: 18:04／不明可） |
| free3 | 出生地の市区町村 |
| free4 | ①こういう未来に行きたい |
| free5 | ②いま感じている課題 |
| free6 | ③今日あえて聞いてみたいこと |
| free10 | 鑑定書URL（自動書き戻し） |

一覧APIは free_fields が空なので**必ず詳細API（get_subscriber_details）を引く**。

## 出生地の解決

`batch_v8.py` が担当。

1. `auto_reading_worker.CITY2PREF` の表で照合（**長い地名から**。「津」が大津・沼津に先に当たる潜在バグ対策）
2. 見つからなければ Haiku 4.5 が都道府県を判定
3. 47都道府県名と一致したときだけ採用
4. 判定不能なら東京都＋ログ「特定できず東京都で計算」

**黙って東京都にしてはいけない。** 渋川市（群馬）・土浦市（茨城）で実際に事故が起きた。出生地が変わるとASCとハウスが全部ずれる。

## 計算してチャートテキストに注入するもの（21節）

`gen_v8.py: build_chart_text()`。Swiss Ephemeris API（localhost:5000）を叩く。

| 種別 | 内容 |
|---|---|
| ネイタル | 天体12・**ドラゴンテイル**・アングル・ハウスカスプ |
| 時間 | プログレス／進行の月の履歴9年／プロフェクション年表24年／トランジット／イングレス |
| 計算済み | **四大元素バランスと同点判定**／サビアン原文（検証済み360度）／セクト／PoF／主要アスペクト表 |
| **エッセンシャルディグニティ** | 七天体の点数と**★城主**。リリー式で機械確定 |
| **今の空からネイタルへの接触** | オーブ3度以内。1度以内は★印 |
| **プロフェクション期間** | 今年と前年を誕生日つきの日付範囲で |
| 裏取り専用 | ソーラーアーク／ソーラーリターン（本文言及禁止） |
| 本人 | 三つの答え |

## コードで確定する理由

第7版まではAIに判断させていた。結果こうなった。

```
城主        同じ人を二度読むと答えが変わる
元素の同点   火6・土6でも「火が優勢」と書く
接触        オーブ56分の合を見落とす（計算して渡していなかった）
年またぎ     55歳なのに「54歳から今この瞬間まで」
```

**AIの裁量をゼロにした項目は、以後ゼロ件で推移している。**

## 城主（ディグニティコード）の決定規則

```
ドミサイル        +5
エグザルテーション +4
トリプリシティ    +3   ※昼夜で主が変わる
デトリメント      -5
フォール          -4
いずれも無い      -5（ペレグリン）
```

点数最高を採る。同点は **アングル配置 → 今年の年主星 → 伝統的な天体順** で自動解決。

**ODAが個別に判断してはいけない。** 再現性がなく、他の講師が引き継げず、なぜその星なのかを読者に説明できなくなる。

低得点の星が城主になることもある。その場合も欠陥として扱わず「どこへ行っても自分の流儀を発明してきた人」の物語にする。**低得点の城主が出た最初の一件は、納品前に必ずODAに読ませる。**
