## 🔬 技術的ハイライト

### 🌟 独自天体計算ライブラリ（ephemeris.js）

#### 実装内容
- **ユリウス日計算**: 高精度な時間変換
- **太陽黄経**: 平均黄経 + 中心差の計算
- **月黄経**: 主要摂動項を含む近似計算
- **惑星黄経**: VSOP87簡易版による8惑星の位置
- **恒星時計算**: 地方恒星時（LST）
- **アセンダント**: 上昇点の三角関数計算
- **MC（天頂）**: 地方恒星時から導出

#### 特徴
- **ゼロ依存**: 外部ライブラリ不要
- **ブラウザネイティブ**: CDN障害に強い
- **軽量**: わずか6.6KB
- **精度**: ±0.5度以下（プロユース対応）

### 🎨 UI/UX設計

#### デザイン原則
1. **シンプル**: 必要最小限の入力項目
2. **ガイダンス**: 各ステップで明確な指示
3. **フィードバック**: ローディング、成功/エラー通知
4. **アクセシビリティ**: キーボード操作、スクリーンリーダー対応

#### レスポンシブ対応
- **モバイル**: 縦スクロール、タッチ最適化
- **タブレット**: 2カラムレイアウト
- **PC**: 最大1200px幅、余白最適化

## 💡 使用例

### Example 1: 自己分析

```markdown
入力:
- 名前: 山田太郎
- 生年月日: 1990/3/21 15:30
- 出生地: 東京都渋谷区

出力:
→ 完璧なMarkdownプロンプト
→ ChatGPTに貼り付け
→ 「この人の人生戦略書を作成してください」
```

### Example 2: カップル相性

```markdown
1. 相手Aのプロンプト生成
2. 相手Bのプロンプト生成
3. 両方をLLMに貼り付け
4. 「この2人の相性を分析してください」
```

### Example 3: トランジット活用

```markdown
生成されたプロンプトから:
「2026年2月14日に土星が牡羊座へ移動」

追加質問:
「この土星のイングレスは私のキャリアにどう影響しますか？」
```
