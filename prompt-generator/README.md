# ✨ Anti-Gravity Prompt Builder v1.0

占星術プロンプト・ジェネレーター（MVP版）

## 🌟 概要

Swiss Ephemeris級の高精度天体計算エンジン（Astronomy Engine）を使用し、ユーザーの出生情報から詳細な天体データを計算。ChatGPT/Gemini等のLLMに読み込ませるための完璧な指示テキスト（プロンプト）を一発生成するWebツールです。

## ⚡ 主な機能

### 📊 高精度天体計算
- **ネイタルチャート**: 10天体（太陽〜冥王星）の精密計算
- **感受点**: ASC（上昇点）、MC（天頂）の計算
- **ハウスシステム**: Placidus法による12ハウス
- **サビアンシンボル**: 360度全ての意味解釈（度数切り上げ）
- **アスペクト**: メジャーアスペクト（0°, 60°, 90°, 120°, 180°）の自動検出

### 🔮 プログレス計算
- **P-太陽**: 現在の人生テーマ
- **P-月**: 現在の感情の流れ
- **月相フェーズ**: 8つの月相サイクル判定

### 🌍 トランジット予報（3年間）
- **木星・土星**: サイン移動（イングレス）のタイミング
- **外惑星**: 天王星・海王星・冥王星の現在位置

### 📍 位置情報
- OpenStreetMap Nominatim APIによる都市検索
- 緯度・経度の自動取得
- タイムゾーンの自動推定

### 📋 プロンプト出力
- Markdown形式の構造化テキスト
- ワンクリックでクリップボードにコピー
- テキストファイルとしてダウンロード可能

## 🚀 使い方

### 1. 情報入力
- お名前を入力
- 生年月日を入力（年/月/日）
- 出生時間を入力（時/分）※不明な場合は12:00に設定
- 出生地を入力し、「位置検索」ボタンをクリック

### 2. プロンプト生成
- 「🌟 プロンプト生成」ボタンをクリック
- 数秒で高精度計算が完了

### 3. 活用
- 生成されたプロンプトをコピー
- ChatGPT, Gemini, Claude等のLLMに貼り付け
- ナレッジファイルと組み合わせて使用

## 🛠 技術仕様

### フロントエンド
- **Pure HTML/CSS/JavaScript** - フレームワーク不要
- **Astronomy Engine** - Swiss Ephemeris級の天文計算ライブラリ
- **レスポンシブデザイン** - PC/スマホ対応

### 天文計算
- **精度**: ±0.001度以下
- **対応期間**: 1600年〜2200年
- **座標系**: 黄道座標（Ecliptic）
- **ハウスシステム**: Placidus（プラシーダス法）

### データ
- **サビアンシンボル**: 360個の完全データベース
- **タイムゾーン**: 世界中の主要都市に対応
