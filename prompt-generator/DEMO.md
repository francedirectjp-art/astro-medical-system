# 🌟 Anti-Gravity Prompt Builder - デモガイド

## 📱 アクセス

ローカル開発サーバー:
```bash
cd prompt-generator
python3 -m http.server 8000
```

ブラウザで開く: `http://localhost:8000`

## 🎯 使い方（ステップバイステップ）

### Step 1: 基本情報の入力

1. **お名前**: 任意の名前を入力
   ```
   例: 山田太郎
   ```

2. **生年月日**: 年月日を入力
   ```
   例: 1990年 3月 21日
   ```

3. **出生時間**: 時刻を入力
   ```
   例: 15時 30分
   ```
   
   ⚠️ 出生時間が不明な場合は「出生時間不明」にチェックを入れると自動的に12:00に設定されます。

### Step 2: 出生地の指定

1. **出生地入力**: 都市名や住所を入力
   ```
   例: 東京都渋谷区
   例: Tokyo
   例: New York
   ```

2. **📍 位置検索ボタンをクリック**
   - OpenStreetMap APIが自動的に検索
   - 緯度・経度が自動入力される
   - タイムゾーンが自動設定される

3. **手動入力も可能**
   - 位置検索後、座標を微調整できます
   - 緯度: -90.0000 〜 90.0000
   - 経度: -180.0000 〜 180.0000
   - タイムゾーン: Asia/Tokyo, America/New_York など

### Step 3: プロンプト生成

1. **🌟 プロンプト生成ボタンをクリック**
   - 数秒間の計算が実行されます
   - ローディングアニメーションが表示されます

2. **計算内容**:
   - ネイタルチャート（10天体の位置）
   - アセンダント（ASC）、天頂（MC）
   - プラシーダスハウスシステム
   - メジャーアスペクト
   - プログレス（現在の内的状態）
   - トランジット（未来3年間の木星・土星の動き）

### Step 4: プロンプトの活用

生成されたプロンプトには以下の情報が含まれます：

#### 📊 ネイタルチャートデータ
```markdown
- 太陽: 牡羊座 0.45度 (House: 10) / サビアン: "牡羊座1度: 女性が水から上がり、アザラシも上がり彼女を抱く"
- 月: 蟹座 15.23度 (House: 1) / サビアン: "蟹座16度: ..."
...
```

#### 🔮 プログレス情報
```markdown
- P-太陽: 牡牛座 12.34度 / 人生のテーマ: "..."
- P-月: 獅子座 5.67度 / サビアン: "..."
- 現在の月相フェーズ: フルムーン期（満月）
```

#### 🌍 トランジット予報
```markdown
### 木星の動き:
  - 2025-05-26 に 蟹座（Cancer）へ移動
  - 2026-06-10 に 獅子座（Leo）へ移動

### 土星の動き:
  - 2026-02-14 に 牡羊座（Aries）へ移動
```

### Step 5: プロンプトのコピー・保存

#### 📋 クリップボードにコピー
- 「📋 クリップボードにコピー」ボタンをクリック
- ChatGPT、Gemini、Claudeなどに直接貼り付け可能

#### 💾 ファイルダウンロード
- 「💾 テキストファイルでダウンロード」ボタンをクリック
- `astro-prompt-YYYY-MM-DD.txt` 形式で保存
- 後から参照したり、複数のLLMで試せます

**入力**:
- あなたの出生情報を正確に入力
- 母子手帳や戸籍で出生時刻を確認するとより精度が高まります

**活用方法**:
1. 生成されたプロンプトをChatGPTに貼り付け
2. 追加で「現在の仕事の転機について教えてください」などの質問を追加

**手順**:
1. 一人目のプロンプトを生成
2. 二人目のプロンプトを生成

## 🔧 トラブルシューティング

### 位置検索が失敗する場合
- より具体的な地名を入力（例: 「東京」→「東京都千代田区」）
- 英語で入力してみる（例: 「Tokyo, Japan」）
- 手動で緯度・経度を入力する

### 計算がエラーになる場合
- 日付が正しいか確認（例: 2月30日は存在しません）
- 時刻が正しいか確認（0-23時、0-59分）
- ブラウザのコンソールでエラーメッセージを確認

### クリップボードコピーが動作しない場合
- HTTPSまたはlocalhostでアクセスしているか確認
- ブラウザの権限設定を確認
- 手動でテキストを選択してコピー

## 💡 Tips & Tricks

### 出生時間が不明な場合
- 正午（12:00）で計算することで、太陽の位置は正確
- 月の位置は±6度程度の誤差がある
- アセンダントとハウスは参考値として扱う

### より詳細な分析を得るには
- 生成されたプロンプトに以下を追加:
  ```
  特に以下の点について詳しく教えてください：
  - 太陽と月のアスペクト
  - 10ハウスのテーマ（キャリア）
  - 現在のプログレス月の影響
  ```

### 複数のLLMで試す
- ChatGPT (GPT-4)
- Claude (Anthropic)
- Gemini (Google)
- それぞれ異なる視点で分析してくれます

## 📊 データの精度について

### 天体位置の精度
- **カスタム天体計算ライブラリ使用**: VSOP87理論ベース
- **誤差**: ±0.5度以下（プロフェッショナルユース対応）
- **対応期間**: 1900年〜2100年

### タイムゾーンの重要性
- **月**: 1日で約13度移動（タイムゾーンのズレが大きく影響）
- **ASC**: 4分で1度移動（出生時間の精度が重要）
- **太陽**: 1日で約1度移動（時間のズレの影響は小さい）

### サビアンシンボル
- **度数の扱い**: 小数点切り上げ
  - 例: 12.01度 → 13度のシンボル
- **ルーツ**: マーク・エドモンド・ジョーンズ／ディーン・ルディア
